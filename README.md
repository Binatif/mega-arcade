# Muhammad's Mega Arcade

A fun Python arcade with a collection of mini-games in one window! It uses a dark neon style with cyan highlights.


## Features

- Snake Clash
- Capybara Clicker
- Capybara Pong
- Head or Tail
- Even or Odd
- Treasure Hunt
- Rock Paper Scissors
- Neon Racer
- Cyber Dodge
- Memory Match
- Space Blaster
- Brick Breaker
- Jump Dash
- Gem Catcher
- Website Linker

## Requirements

- Python 3
- Tkinter (usually included with Python on many systems)

The arcade also uses Python's built-in `random` and `webbrowser` modules.

## How to Run

1. Save the Python file as `omega_platform.py`.
2. Open a terminal in the folder where the file is saved.
3. Run:

   ```bash
   python3 omega_platform.py
   ```

## Controls

Controls depend on the game. Common controls include:

- **Arrow keys** to move or steer.
- **W / S** and **Up / Down** for paddles in Capybara Pong.
- **Space** to jump or drop items in some games.
- **Mouse movement** to control the paddle in Brick Breaker.
- **R** to respawn in Oozy Lab.
- **Esc** to return home in some games.
- Use the on-screen buttons and instructions when available.

## Website Linker

Enter a website address such as `google.com` or `youtube.com` and press **OPEN**. You can also type a search phrase to search with Google. This opens the page in your default web browser.

## Notes

- This is a desktop Tkinter application, not a website or mobile app.
- Some games end when you hit an obstacle or miss an object.
- To return to the arcade menu, use the game's **BACK** button when available.
- If Tkinter is missing on Ubuntu, you may need to install the system package for Tkinter.

Have fun playing!
